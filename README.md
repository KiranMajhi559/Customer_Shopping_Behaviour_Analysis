# Customer_Shopping_Behaviour_Analysis
A data analysis project that explores customer shopping patterns, product preferences, and spending behavior using Python, SQL, and Power BI to generate business insights.

This project demonstrates an end-to-end data analytics workflow, starting from raw data processing to delivering business insights through dashboards and reports.

The objective is to analyze the dataset, identify patterns, and provide actionable insights using Python, SQL, and Power BI.

## 📂 Dataset
Structured dataset containing customer and transaction-related data
Includes features such as:
Demographics (age, gender, etc.)
Purchase details (products, categories, amount)
Customer behavior (frequency, ratings, discounts)
Data required cleaning due to:
Missing values
Inconsistent column formats

## 🛠️ Tools & Technologies
Python (Pandas, NumPy) → Data cleaning & EDA
SQL (PostgreSQL) → Data analysis
Power BI → Dashboard & visualization
Gamma → Presentation (PPT)
Excel/CSV → Data source

## 🔄 Project Steps
1. **Data Loading & Exploration (Python):**
    Imported dataset using Pandas
    Checked structure using .info() and .describe()
    Identified missing values and data types
   
3. **Data Cleaning & Transformation:**
    Handled missing values using appropriate methods
    Standardized column names
    Created new features for better analysis
    Removed redundant or unnecessary columns
   
5. **Exploratory Data Analysis (EDA):**
    Analyzed trends and distributions
    Compared different customer segments
    Identified key patterns in purchases and behavior
   
7. **SQL Analysis:**
    Loaded cleaned data into a relational database
    Wrote SQL queries to answer business questions:
    Revenue analysis
    Customer segmentation
    Product performance
    Behavioral insights
   
9. **Dashboard Development (Power BI):**
    Built an interactive dashboard to visualize insights
    Used charts, KPIs, and filters for better understanding
   
11. **Reporting & Presentation:**
     Created a structured report summarizing findings
     Designed a professional PPT using Gamma for presentation

## 📈 Dashboard
The Power BI dashboard includes:

KPI metrics (Total Customers, Revenue, Average Values)
Sales and revenue breakdowns
Customer segmentation visuals
Interactive filters for dynamic analysis

## 📊 Results & Insights
Identified high-value customer segments
Analyzed product performance across categories
Observed impact of discounts and promotions
Found patterns in customer purchasing behavior
